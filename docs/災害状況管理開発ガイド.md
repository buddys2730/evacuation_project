1. 概要

本システムは災害状況（危険区域ポリゴン）の登録・検索・地図表示を行うWebアプリ＋APIです。
管理者はポリゴン（地図上の範囲）、災害種別、深さ、危険度、コメント等を登録でき、登録内容は地図上で一覧・可視化できます。

3. DBテーブル仕様

disaster_situations（危険区域・災害状況）

| カラム名           | 型        | 説明          |
| -------------- | -------- | ----------- |
| id             | int      | PK          |
| disaster\_type | str      | 災害種別（例: 洪水） |
| danger\_level  | str      | 危険度（高/中/低）  |
| depth\_m       | float    | 深さ(m)       |
| is\_closed     | bool     | 通行止めフラグ     |
| geometry       | POLYGON  | ポリゴン(GIS型)  |
| occurred\_at   | datetime | 発生日         |
| cleared\_at    | datetime | 復旧日         |
| comment        | text     | コメント        |
| image\_url     | text     | 画像URL       |
| created\_at    | datetime | 登録日         |
| updated\_at    | datetime | 更新日         |


4. API仕様

[POST] /api/disaster_situations
説明: 新規災害状況の登録
Body例

{
  "disaster_type": "洪水",
  "danger_level": "高",
  "depth_m": 2,
  "is_closed": true,
  "geometry": { "type": "Polygon", "coordinates": [[[..., ...], ...]] },
  "occurred_at": "2025-06-25",
  "cleared_at": "2025-06-26",
  "comment": "大雨洪水警報",
  "image_url": ""
}

成功時: { "id": 7 }
[GET] /api/disaster_situations
説明: 全登録災害状況をGeoJSONで取得（地図描画用）
戻り値例

[
  {
    "id": 7,
    "disaster_type": "洪水",
    "danger_level": "高",
    "depth_m": 2,
    "is_closed": true,
    "geometry": { "type": "Polygon", "coordinates": [[[133.29,34.54], ...]] },
    "occurred_at": "2025-06-25T00:00:00",
    "cleared_at": null,
    "comment": "TEST",
    "image_url": "",
    "created_at": "...",
    "updated_at": "..."
  },
  ...
]

CORSについて
本番運用はCloudflare TunnelやngrokなどでCORS対応が必要。
routes.py で CORS(app, origins="*", supports_credentials=True) と設定。

6. フロントエンド連携

フロント（React等）からは /api/disaster_situations へPOST・GETで連携。
GETで受けたデータの geometry をそのままGeoJSONとして地図描画コンポーネントに渡せばOK。
7. よくあるトラブル／デバッグ

「can't adapt type 'WKBElement'」エラー
→ geometryを取得時は必ずST_AsGeoJSON()で文字列化してから扱う
「TypeError: cannot convert dictionary update sequence element #0 to a sequence」
→ dict(row)で失敗。必ず.mappings().all()または明示的に d = {k: v for k, v in row.items()} で変換
CORS 500/403エラー
→ Flask側CORS許可設定 or トンネル側Origin制御が必要
日付型不正
→ datetime型は .isoformat() で文字列化
