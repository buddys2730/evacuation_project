管理ダッシュボード：通行止め・危険区域一覧表示UI設計

（2025-06-22）

1. 概要
   管理ダッシュボードで「現在の通行止め・危険区域」を
   　市内単位で地図＋カードUIで分かりやすく可視化。
   カードには町名・番地“辺り”／付近で位置を表示し、ピンポイントではなく範囲・目安となる地名で表現。
   地図とカードは連動（カード選択→地図上ハイライト）。
2. 画面レイアウト・操作フロー
   地図エリア（MapLibreGL推奨、全件の危険ポリゴン/ラインを重畳表示）
   カード一覧エリア（サイドパネルまたは下部）
   各カードに：
   災害種別
   町名・番地“辺り”のラベル（例：「松永町3丁目15番地辺り」）
   危険度
   発生／通報日時
   コメント
   クリックで地図上ハイライト
   「市区町村」「災害種別」で絞り込み
3. 住所ラベル生成ロジック
   geometry（ポリゴン/ライン/点）の重心または代表点を逆ジオコーディングし「町名・番地“辺り”」を自動付与
   複数町域またがる場合は「◯◯町～△△町付近」など合成ラベル
   管理者がUI上でラベル手編集可（例：「◯丁目西側」等）
4. API仕様例（管理者向け）
   一覧取得API
   GET /admin/disaster-situations?city=福山市&is_closed=true
   レスポンス例
   [
   {
   "id": 1,
   "disaster_type": "土砂災害",
   "danger_level": "高",
   "address_label": "松永町3丁目15番地辺り",
   "area_label": "松永町3丁目～神村町付近",
   "occurred_at": "2025-06-22T09:00:00Z",
   "comment": "崩落の危険あり"
   },
   ...
   ]
   address_label / area_labelはサーバー側で自動生成し、必要なら編集APIで更新可能
5. その他仕様
   座標（緯度経度）は画面には一切表示しない
   フロントは既存UIのMap＋カードコンポーネント流用で拡張可
   フィルタ・検索もラベルベース
6. 将来対応
   現場写真連携、IoT連携は将来設計フックのみ記載し現段階未実装
   住民側システムとの違い

ユーザー側は「半径指定地図表示＋危険警告（カード無し）」
管理者側は「市内単位の一覧＋地名/範囲ラベル付きカード＋危険区域地図重畳」
