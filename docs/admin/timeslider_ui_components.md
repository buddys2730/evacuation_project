タイムスライダーUI主要コンポーネント設計（2025-06-22）

1. タイムスライダーコンポーネント
UI要素:
スライダー（バー＆つまみ）
範囲選択（ドラッグ/クリックで開始・終了日付）
日付ピッカー併用
[前日][次日][再生]ボタン
振る舞い:
1日／3日間／カスタム範囲で可変
ドラッグでアニメーション再生（災害状況の推移が動的に地図とカードに反映）
2. 地図コンポーネント
MapLibre GL JS／Leaflet等想定
選択期間内の全災害範囲（ポリゴン/ライン/点）を重畳表示
カード選択で該当範囲をハイライト・自動ズーム
3. カードリストコンポーネント
表示内容
災害種別
address_label（例：「松永町3丁目15番地辺り」）
危険度
発生日時
解除日時
コメント
並び順は発生日時／危険度
カードクリックで該当範囲ハイライト
4. CSVエクスポートボタン
現在のフィルタ状態そのままCSVダウンロード
フロントは単純な「ダウンロード」ボタン
5. フィルタバー
市区町村
災害種別
危険度
期間（from/to）
6. 主要APIエンドポイントまとめ
GET /admin/disaster-situations
クエリ：city, from, to, disaster_type, danger_level
GET /admin/disaster-situations/export
クエリ：上記と同じ、CSV形式でDL
7. 動作シーケンス例
管理者が期間・市区町村・種別を指定（またはタイムスライダーで期間指定）
APIから該当災害データを取得
地図上で災害範囲全件を重畳
カードリストに全件表示、クリックでハイライト
必要にCSVダウンロード
実装フローメモ（例）

Reactの場合
<TimeSlider /> → 期間選択でAPI再取得
<MapViewer /> → geometry配列を描画、selectedIdでハイライト
<DisasterCardList /> → データリスト、クリックでハイライト
<ExportCsvButton /> → クリックでCSVエンドポイント叩く
補足
