# SearchForm コンポーネント定義書

| プロパティ名      | 型      | 必須 | 説明                                  |
|-------------------|---------|------|---------------------------------------|
| `onResults`       | Func    | ✅   | 検索実行時、検索結果データを返す関数  |
| `onSearchParams`  | Func    | ✅   | 検索パラメータ決定時に呼ばれる関数    |
| `defaultRadius`   | Number  | ❌   | デフォルト検索半径                    |
| `setUserLocation` | Func    | ❌   | ユーザー位置取得時コールバック        |
