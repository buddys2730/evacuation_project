# 07. AR連携やフロントエンドの開発ドキュメント

## 1. AR機能実装概要

- 現状はWebAR（A-Frame）を採用  
- GPS位置情報を用いた避難所情報のAR表示  
- 主要機能：  
  - 避難所名の3D表示  
  - 避難誘導矢印の表示  
  - 動的に避難所データを読み込み反映

---

## 2. 技術スタック

- フロントエンド：React + A-Frame + AR.js  
- 位置情報取得：ブラウザのGeolocation API  
- API連携：REST API（Flaskバックエンド）  
- 地図表示：Google Maps API（通常画面）

---

## 3. 状態管理・画面遷移設計

- React Routerでルート管理  
- グローバル状態管理はReact Context利用  
- 避難所選択→AR表示画面へパラメータ渡しで連携  
- UI要素はアクセシビリティ配慮で設計

---

## 4. 使用外部ライブラリ一覧

| ライブラリ名   | 用途                        | バージョン例      |

---

## 5. 開発上の注意点

- iOS Safariでは位置情報許可を必ず確認  
- バッテリー消費とパフォーマンスに注意  
- 端末間での表示差異を検証し対応  
- ネットワーク遅延を考慮したUX設計
