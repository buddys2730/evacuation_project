# ResultCardList コンポーネント定義書

## 📌 目的

避難所検索の結果をカードUIで一覧表示し、クリックで選択状態と連動する。

## 📂 配置パス

`frontend/src/components/ResultCardList.js`

## 📥 入力 Props

| プロパティ名 | 型     | 必須 | 説明                   |
| ------------ | ------ | ---- | ---------------------- |
| `points`     | Array  | ✅   | 検索結果の避難所リスト |
| `selectedId` | String | ❌   | 選択中の避難所ID       |
| `onSelect`   | Func   | ✅   | カードクリック時の処理 |

## 📤 出力内容

- 検索結果をカード形式でレンダリング
- クリック時に onSelect をコール

## 🔗 依存ファイル

- `ResultCardList.css` … スタイル

## 🔁 呼び出し元

- `App.js`など

## ✅ 開発契約チェック項目

- [x] 選択中IDとカードの選択状態が連動
- [x] points配列が空の場合は「検索結果がありません」と表示
- [x] onSelectコールバックが正しく動作

## 🚨 禁止事項

- 直接stateや外部変数で選択管理しないこと（props経由のみ）
